BYOB: Bring Your Own Bike 2026

Python · LightGBM · Claude API · Streamlit · Docker

Simulating how product nudges change the way people commute, with LLM agents.

An end-to-end agentic pipeline on Microsoft’s GeoLife GPS trajectories. A LightGBM model infers how people travel from GPS alone, with no extra sensors. Claude writes each user a carbon report, fact-checked by a Judge–Critic agent loop and validated against human labels with Cohen’s κ.

Fifteen LLM-driven commuters on a social graph then live through a simulated week under escalating Apple ESG nudges. Car use and CO₂ fell at every level.

RentalGPT 2023

Python · PyTorch · Dash · Docker · Kubernetes · GCP

Rental market analytics, price prediction, and an LLM assistant in one app.

Built on Two Sigma’s RentHop listing data. Features fuse tabular attributes, BERT sentiment from listing text, and YOLOv5 detections from listing photos to predict rent and renter interest.

A Dash app brings listings, analysis, and predictions together with an open-source LLM chat assistant, deployed with Docker and Kubernetes on GCP.
